02 / My approach

Start with the work.
Then build the tool.

The best technology is the kind that removes friction without introducing a new layer of complexity.

01 / Understand

Get close to the problem.

Understand the people, constraints, data, and workflows before deciding what to build.

02 / Simplify

Build the smallest useful thing.

Prefer clear interfaces, simple systems, and existing tools over unnecessary architecture.

03 / Deliver

Make it work in context.

Connect it to real systems, test with users, and improve based on observable outcomes.
